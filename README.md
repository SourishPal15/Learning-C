## 📖 About This Repository

This repository documents my **C programming journey**.

I started learning C from the fundamentals and created this repository to keep track of what I learn, the programs I write, and the concepts I practice along the way.

Instead of simply following tutorials, I try to **implement what I learn by writing programs myself**.

The repository is continuously updated as I learn new concepts.

> 💡 **Learn → Practice → Build → Improve**
